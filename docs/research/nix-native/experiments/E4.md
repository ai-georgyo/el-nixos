# E4: pieced references in the glibc split outputs (+ lateReferrers)

Design §9 E4 / §2.8 / WP0d.  Question: in the per-subpackage outputs of the
relocated glibc, which outputs other than `out` hold references to the compile
prefix that Nix's hash scanner cannot see, or whose path cannot be parsed
(gcc's store-by-pieces), so they need `opaqueRefs` acks and
`nix-support/hidden-references`?  Second deliverable: the `lateReferrers`
list (which sibling outputs reference `common`, `nss_db`, `utils`).

Date 2026-10-18, agent `glibc` (branch `nn/glibc`).

## Inputs

* **[NF-S3]** single-prefix relocated build, `spikes-nixpkgs-faithful/glibc-reloc.nix`:
  `/nix/store/nncpaslng931rr3ipkb4zsh3a4vabvdq-glibc-2.39-142.el10_2`
  (the compile prefix `%_prefix`).
* **[NF-S5]** split, `spikes-nixpkgs-faithful/split.nix` with
  `merges = [ [ "glibc" "glibc32" ] ]` (as in the design): 223 outputs, `out` =
  `/nix/store/v976jawa992q5hp7xmfd4215w8dg0xxk-glibc-2.39-142.el10_2`.  All
  were still valid in the store (no rebuild; `nix build --dry-run` had nothing to do).

  Important property of S5: `split.nix` rewrote only *full* occurrences of the
  S3 path to the S5 `$out` (same length).  Any S3 hash still present in an S5
  output is therefore exactly a copy the full-path rewrite could not match —
  i.e. what a real build (compile prefix = `$out`, no rewrite) has as a
  truncated/pieced `$out`.  Scanning S5 for the **S3 hash** answers E4 for
  the real build; the S3 tree itself (no rewrite at all) is scanned as a
  cross-check.

## Why not `fragscan.py` as is

`docs/research/nix-native/fragscan.py ROOT` looks for 8-byte windows of the
*root's own path* not covered by a full occurrence.  Run over every S5 output
(`fragscan-s5.txt`): 10 outputs report "files with fragments" (benchtests 416,
gconv_extra 246, out 30, sysroot 22, common 10, utils 4, nss_db 2, dev, libnsl,
nss_hesiod 1), but its own-hash column is 0 everywhere: for an output Y ≠ out
the windows are `/nix/sto…` and `…-glibc-2.39-142.el10_2` that every full
`$out/...` reference also contains.  Pure false positives, and it misses what
matters (pieces of `$out`, not of Y).  F-2's "57 pieced windows in ld.so
`.rodata`" are the same effect plus one real finding (below).

Replacement, `piecescan.py` (appendix A), hash-based, two classes per file and
per target hash H:

* **truncated copy**: H occurs in full but is *not* followed by the whole store
  name `-glibc-2.39-142.el10_2`.  Nix's scanner sees the reference (full hash),
  the partitioner cannot parse `$out/rel` from it.
* **split hash**: an 8-byte window of H outside every full H.  This is what
  Nix's scanner would miss (a hidden edge).

```sh

    v976jawa992q5hp7xmfd4215w8dg0xxk=S5out > e4-report.txt        # 26 s

```

## Results

### Split hashes: none outside DWARF, all of them the random-seed flag

1113 split-hash windows in S5 (2199 in S3, incl. `lib/debug`), **every one**
inside `-frandom-seed=nncpaslng9` in `.debug_str` (checked by `seedcheck.py`,
appendix C): nixpkgs' reproducible-builds hook ([F-1]), 10 hash characters, no
32-char hash, so harmless for Nix and gone with the hook off (§5.1).  Files:
`dev`/`out` `libmcheck.a`, `out` ld.so, and the unstripped libraries of
`sysroot_x86_64_el10_glibc` (libm.so.6 969 windows).  **No split hash in any
loaded section of any output**, and none for the S5 `$out` hash.

### Truncated copies of the prefix (the store-by-pieces strings)

Exactly 7 files, identical in S5 and in S3:

| output | file | section | rest of the path (decoded from `.text` immediates / `.rodata` overlap) |
|---|---|---|---|
| out | `lib64/ld-linux-x86-64.so.2` | `.rodata` | `2/lib64/` → `$out/lib64/` (system dir) |
| out | `sbin/ldconfig` | `.rodata` (field padded with spaces) | `2/lib64/` |
| **common** | `bin/locale` | `.rodata` | `l10_2/lib/locale/LC_IDENTIFICATI…` (overlapping store) → `$out/lib/locale/…` |
| **common** | `bin/localedef` | `.rodata` | `39-142.el10_2/share/i18n/locales`, `…/charmaps` → `$out/share/i18n/…` |
| **static** | `lib64/libc.a` (member `dl-load.o`) | ar member data | `2/lib64/` |
| **sysroot_x86_64_el10_glibc** | `x86_64-redhat-linux/sys-root/el10/usr/lib64/ld-linux-x86-64.so.2` | `.rodata` | `2/lib64/` |
| **sysroot_x86_64_el10_glibc** | `x86_64-redhat-linux/sys-root/el10/usr/lib64/libc.a` (`dl-load.o`) | ar member data | `2/lib64/` |

Shape: a 64-byte `.rodata` chunk `/nix/store/<32-char hash>-glibc-2.39-142.el10_`
(11 + 32 + 21 bytes) loaded with vector moves, the tail stored by `movabs`
immediates (`2/lib64/`) or by a second, overlapping chunk.  The **hash is
always whole** (it ends at byte 43 < 64), so Nix registers the edge: S5's
`nix-store -q --references` shows `common`, `static`, `out`, `sysroot` →
the *S3* path, i.e. exactly these copies.  (Where gcc cuts the string
depends on its length and on gcc's choices; "hash whole" is measured for this
build, not guaranteed, hence the split-hash detector below.)

Nothing is hidden from Nix; in the 5 files outside `out` only the path behind
the piece is opaque.  All of them point into `out` (`lib64/`, the system dir),
into a union/search-path dir (`lib/locale` → `LOCPATH`) or into a dangling
default (`share/i18n` → `I18NPATH`, owned by `locale_source`), and every one
of these outputs references `out` anyway.  32-bit binaries (`lib/`, merged
`glibc32`): none.  Debug files (S3 `lib/debug`, the future `debug` output):
only the random-seed windows.

### `opaqueRefs` for glibc (outputs ≠ out)

```nix
opaqueRefs = [
  "common/bin/locale"                       # $out/lib/locale/... (LOCPATH)
  "common/bin/localedef"                    # $out/share/i18n/{locales,charmaps} (I18NPATH)
  "static/lib64/libc.a"                     # dl-load.o: $out/lib64/ (system dir)
  "sysroot_x86_64_el10_glibc/x86_64-redhat-linux/sys-root/el10/usr/lib64/ld-linux-x86-64.so.2"
  "sysroot_x86_64_el10_glibc/x86_64-redhat-linux/sys-root/el10/usr/lib64/libc.a"
];
```

(in `packages/glibc/default.nix`; `out`'s two files are allowed without ack.)

### Reference graph and `lateReferrers`

From Nix's registered references of the 223 S5 outputs (`refgraph.py`,
appendix B; symlinks included, which a content scan of regular files misses):

```

dev         <- sysroot

```

No cycle.  Late outputs (§4.6, transitive closure of referrers):

| late output | lateReferrers |
|---|---|
| `common` | 138 of the 206 `langpack_*` outputs (the other 68 — `de`, `ja`, `zh`, … — ship their own `LC_CTYPE`); not `minimal_langpack` (empty) |
| `nss_db` | `nss_devel` |
| `utils` | none |
| `benchtests` | none (added: python3/bash shebangs, late-bound like `utils`) |

The exact lists are committed as `packages/glibc/late-referrers.nix`
(generated by `gen-late.py`, appendix B), imported by `packages/glibc/default.nix`.
The design draft's `[ "minimal_langpack" "langpack_*" ]` would be a superset
(70 extra bound copies); the partitioner's verification catches a list that
becomes incomplete when Rocky's locale data changes.

## Verdict / consequences

* `opaqueRefs` for glibc: the 5 entries above; no `hidden-references` are
  *needed* for correctness (the hash is whole), registering them anyway is harmless.
* For WP5 (partitioner Phase G), the detector should be hash-based:
  (1) full `$out` hash not followed by the complete store name → "truncated
  copy" (needs an ack outside `out`), (2) 8-byte windows of the **hash** outside
  full hashes → "split hash" (hidden edge; register + ack).  Windows of the
  full *path* (fragscan/F-2 style) produce false positives for every ordinary
  `$out` reference in non-prefix outputs.
* Static archives must be scanned too (`libc.a`'s `dl-load.o`), not only ELF
  files; section mapping needs the member offset.
* The reproducible-builds random seed is the only split-hash source: keep the
  hook off (§5.1), or the partitioner must allow `-frandom-seed=` in DWARF.

## Appendix A: `piecescan.py`

```python
# E4: pieced (store-by-pieces) references in split outputs.
# usage: python3 -I piecescan.py OUTS_FILE HASH[=LABEL]... > report
#   OUTS_FILE: one output store path per line (name = suffix after the version)
#   HASH:      32-char store hash parts to look for (the compile prefix(es))
# For every regular file of every output: occurrences of each HASH that are not
# followed by the whole store name (truncated copies: the rest of the path is
# assembled by code), and 8-byte windows of HASH that are NOT inside a full
# occurrence (split hashes: what Nix's 32-char scanner cannot see).  ELF
# offsets are mapped to sections.
# Also prints, per output, which sibling hashes Nix's scanner finds in full
# (the reference graph) so hidden edges stand out.
import os, re, subprocess, sys, json
from collections import Counter, defaultdict

outs_file, hashes = sys.argv[1], sys.argv[2:]
targets = []
for h in hashes:
    hh, _, label = h.partition('=')
    targets.append((hh.encode(), label or hh[:8]))
outs = {}
for line in open(outs_file):
    p = line.strip()
    if not p:
        continue
    m = re.match(r'/nix/store/([a-z0-9]{32})-glibc-2\.39-142\.el10_2-?(.*)$', p)
    outs[m.group(2) or 'out'] = (p, m.group(1).encode())
hash2out = {h: n for n, (p, h) in outs.items()}
NAME = b'-glibc-2.39-142.el10_2'
W = 8

def sections(path):
    r = subprocess.run(['readelf', '-SW', path], capture_output=True, text=True).stdout
    s = []
    for l in r.splitlines():
        m = re.match(r'\s*\[\s*\d+\]\s+(\S+)\s+(\S+)\s+[0-9a-f]+\s+([0-9a-f]+)\s+([0-9a-f]+)', l)
        if m and m.group(2) != 'NOBITS':
            s.append((m.group(1), int(m.group(3), 16), int(m.group(4), 16)))
    return s

def secname(secs, i):
    for n, o, z in secs:
        if o <= i < o + z and n != 'NULL':
            return n
    return '?'

refs = defaultdict(set)          # output -> sibling outputs found in full (Nix scanner)
pieced = []                      # (output, rel, label, #full, truncated/section, #split, split/section, samples)
for name, (root, _) in sorted(outs.items()):
    for d, ds, fs in os.walk(root):
        for f in fs:
            p = os.path.join(d, f)
            if os.path.islink(p) or not os.path.isfile(p):
                continue
            b = open(p, 'rb').read()
            for m in re.finditer(rb'/nix/store/([a-z0-9]{32})', b):
                if m.group(1) in hash2out:
                    refs[name].add(hash2out[m.group(1)])
            for H, label in targets:
                full = [m.start() for m in re.finditer(re.escape(H), b)]
                # full hash, but not followed by the whole store name: a truncated /
                # pieced copy of the prefix (the rest is assembled by code)
                trunc = [s for s in full if b[s + 32:s + 32 + len(NAME)] != NAME]
                cov = set()
                for s in full:
                    cov.update(range(s, s + len(H)))
                win = set()
                for k in range(len(H) - W + 1):
                    w = H[k:k + W]
                    i = b.find(w)
                    while i >= 0:
                        if i not in cov:
                            win.add(i)
                        i = b.find(w, i + 1)
                if not win and not trunc:
                    continue
                secs = sections(p) if b[:4] == b'\x7fELF' else []
                bysec = Counter(secname(secs, i) if secs else 'file' for i in win)
                tsec = Counter(secname(secs, i) if secs else 'file' for i in trunc)
                samples = []
                for i in sorted(trunc)[:4] + sorted(win)[:2]:
                    samples.append(b[max(0, i - 16):i + 24])
                pieced.append((name, os.path.relpath(p, root), label, len(full), dict(tsec), len(win), dict(bysec), samples))

print('== truncated copies (full hash not followed by the store name) and split-hash windows')
print('output\tfile\thash\tfull-hash\ttruncated-by-section\tsplit-windows\tsplit-by-section')
for name, rel, label, nf, tsec, nw, bysec, _ in pieced:
    print(f'{name}\t{rel}\t{label}\t{nf}\t{json.dumps(tsec, sort_keys=True)}\t{nw}\t{json.dumps(bysec, sort_keys=True)}')
print()
print('== samples')
for name, rel, label, nf, tsec, nw, bysec, samples in pieced:
    for s in samples:
        print(f'{name}/{rel} [{label}] {s!r}')
print()
print('== reference graph seen by the hash scanner (full hashes of sibling outputs)')
for name in sorted(outs):
    r = sorted(refs[name] - {name})
    if r:
        print(f'{name} -> {" ".join(r)}')
```

```python
# E4 part 2: sibling reference graph of the S5 split (as registered by Nix) and the
# lateReferrers of the late outputs (design §2.9: L* = L ∪ {Y | Y ->* L}).
# usage: python3 -I refgraph.py OUTS_FILE LATE_OUTPUT...
import re, subprocess, sys, json

outs_file, late = sys.argv[1], sys.argv[2:]
path2out, outs = {}, {}
for line in open(outs_file):
    p = line.strip()
    if p:
        m = re.match(r'/nix/store/[a-z0-9]{32}-glibc-2\.39-142\.el10_2-?(.*)$', p)
        outs[m.group(1) or 'out'] = p
        path2out[p] = m.group(1) or 'out'
# one query per output (over several paths nix-store prints the union)
edges = {}
for n, p in sorted(outs.items()):
    refs = subprocess.run(['nix-store', '-q', '--references', p], capture_output=True, text=True, check=True).stdout.split()
    edges[n] = sorted(path2out[x] for x in refs if x in path2out and x != p)
    other = sorted(x for x in refs if x not in path2out)
    if other:
        print(f'# {n}: non-sibling references: {other}', file=sys.stderr)

print('== edges (output -> siblings it references)')
by_target = {}
for n, ts in edges.items():
    for t in ts:
        by_target.setdefault(t, []).append(n)
for t in sorted(by_target):
    srcs = by_target[t]
    lp = [s for s in srcs if s.startswith('langpack_')]
    rest = [s for s in srcs if not s.startswith('langpack_')]
    print(f'{t} <- {" ".join(rest)}' + (f' + {len(lp)} langpack_*' if lp else ''))

print()
print('== lateReferrers: transitive sibling referrers of each late output')
res = {}
for L in late:
    seen, todo = set(), [L]
    while todo:
        x = todo.pop()
        for s in by_target.get(x, []):
            if s not in seen:
                seen.add(s); todo.append(s)
    seen.discard(L)
    res[L] = sorted(seen)
    lp = [s for s in res[L] if s.startswith('langpack_')]
    print(f'{L}: {len(res[L])} referrers; non-langpack: {[s for s in res[L] if not s.startswith("langpack_")]}; langpack_*: {len(lp)}')
all_lp = sorted(n for n in outs if n.startswith('langpack_'))
for L, v in res.items():
    lp = [s for s in v if s.startswith('langpack_')]
    if lp:
        print(f'{L}: langpacks referencing it = all {len(all_lp)} langpack outputs: {lp == all_lp}; missing: {sorted(set(all_lp) - set(lp))}')
json.dump(res, open('late-referrers.json', 'w'), indent=1, sort_keys=True)
```

```python
# writes packages/glibc/late-referrers.nix from late-referrers.json (refgraph.py)
import json, sys
d = json.load(open(sys.argv[1]))
out = ['# lateReferrers for glibc (design §2.9, §11.3): for each late-bound output, the',
       '# sibling outputs that reference it, transitively.  Generated from the',
       '# reference graph Nix registered for the nixpkgs-faithful S5 split',
       '# (docs/research/nix-native/experiments/E4.md); the partitioner verifies it',
       '# (an incomplete list is a build error), so it is static and checked.',
       "#   common: langpacks whose LC_CTYPE is a symlink to common's C.utf8/LC_CTYPE",
       '#           (identical files grouped by the spec); the other langpacks ship',
       '#           their own LC_CTYPE and do not reference common',
       "#   nss_db: nss_devel (libnss_db.so -> nss_db's libnss_db.so.2)",
       '#   utils:  nothing references it',
       '{']
for k in sorted(d):
    v = d[k]
    if not v:
        out.append(f'  {k} = [ ];')
        continue
    out.append(f'  {k} = [')
    line = '   '
    for n in v:
        s = f' "{n}"'
        if len(line) + len(s) > 88:
            out.append(line)
            line = '   '
        line += s
    out.append(line)
    out.append('  ];')
out.append('}')
open(sys.argv[2], 'w').write('\n'.join(out) + '\n')
print({k: len(v) for k, v in d.items()})
```

## Appendix C: `seedcheck.py`

```python
# every split-hash window (8-byte window of H outside a full H) inside "-frandom-seed=<H[:10]>"?
import os, sys
H = b'nncpaslng931rr3ipkb4zsh3a4vabvdq'
SEED = b'-frandom-seed=' + H[:10]
tot = ok = 0
for line in open(sys.argv[1]):
    root = line.strip()
    for d, ds, fs in os.walk(root):
        for f in fs:
            p = os.path.join(d, f)
            if os.path.islink(p) or not os.path.isfile(p):
                continue
            b = open(p, 'rb').read()
            if H[:8] not in b and H[8:16] not in b and H[16:24] not in b and H[24:] not in b:
                continue
            full = set()
            i = b.find(H)
            while i >= 0:
                full.update(range(i, i + 32)); i = b.find(H, i + 1)
            seed = set()
            i = b.find(SEED)
            while i >= 0:
                seed.update(range(i + 14, i + 24)); i = b.find(SEED, i + 1)
            for k in range(25):
                w = H[k:k + 8]; i = b.find(w)
                while i >= 0:
                    if i not in full:
                        tot += 1
                        ok += all(j in seed for j in range(i, i + 8))
                    i = b.find(w, i + 1)
print(f'split-hash windows: {tot}, inside -frandom-seed=nncpaslng9: {ok}')
```
